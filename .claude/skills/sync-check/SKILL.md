# 設計書 ↔ 実装 網羅的同期チェック

`/update-docs` が「変更駆動」で差分を反映するのに対し、このスキルは「全量照合」で設計書と実装の乖離を検出する。

**実行タイミング**: フェーズ完了時、push 前、大規模リファクタリング後

---

## 事前準備: パス検出

```bash
SCRIPTS_DIR="Assets/Scripts"
SCENES_DIR="Assets/Scenes"
```

---

## Step 1: スクリプト一覧の照合

### 手順

1. `Assets/Scripts/` 配下の全 `.cs` ファイル一覧を取得

```bash
find "$SCRIPTS_DIR" -name "*.cs" | sort
```

2. `docs/設計書/スクリプト一覧.md` を読む

3. 照合:
   - **コードに存在するが設計書にないクラス** → 追加漏れ
   - **設計書にあるがコードに存在しないクラス** → 削除漏れ

---

## Step 2: コンポーネント一覧の照合

`docs/設計書/コンポーネント一覧.md` と `docs/設計書/スクリプト一覧.md` を照合する。
MonoBehaviour クラスが一方にのみ記載されていないか確認する。

---

## Step 3: シーン一覧の照合

```bash
find "$SCENES_DIR" -name "*.unity" | sort
```

`docs/設計書/シーン一覧.md` のシーン一覧と照合する。

---

## Step 4: プレハブ一覧の照合

```bash
find Assets/Prefabs -name "*.prefab" | sort 2>/dev/null || echo "Prefabs フォルダなし"
```

`docs/設計書/プレハブ一覧.md` の Prefab 一覧と照合する。

---

## Step 5: 機能設計書のタスクステータス照合

```bash
# 未完了タスクが残っている features ファイルを検出
grep -l "🔵\|🟡" docs/features/*.md 2>/dev/null

# completed/ 内に未完了タスクが残っていないか
grep -l "🔵\|🟡" docs/features/completed/*.md 2>/dev/null
```

---

---

## Step 7: 乖離の修正

乖離が見つかった場合:
1. 各設計書を修正（改訂履歴も更新）
2. 修正内容をユーザーに報告し確認を求める
3. 確認後コミット → `docs/.doc-sync.md` に記録
